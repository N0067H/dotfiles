# Desktop themes

```sh
just themes
just theme ocean
```

Each preset in `themes/<name>/` contains a `preset.json` (Noctalia palette,
mode, and repository-relative wallpaper path) and a `niri.kdl` (border colors).
`niri/theme.kdl` links to the selected preset. Niri watches the included file
and reloads it live. Noctalia selection and wallpaper are saved through its IPC.

The current `ocean` preset selects OceanDusk and the slightly brightened night
sea. The palette source is `noctalia/palettes/OceanDusk.json`; `setup.sh` links
it into the Noctalia config directory. The script backs up existing local
palette files before linking them.

To add a preset, create its directory and JSON/KDL files, add its palette under
`noctalia/palettes/`, and add a corresponding palette link to `setup.sh`.
Run `just check` before applying it. Desktop presets intentionally manage only
Noctalia, Niri border colors, and wallpaper. Application appearance stays in:

| Application | Settings |
| --- | --- |
| Kitty | `kitty/kitty.conf`; Ayu Mirage, background `#1F2430`, opacity `0.60` |
| Helix | `helix/config.toml`, `helix/themes/ayu_mirage_bright.toml` |
| Hyprland | `hypr/hyprland.lua`, `hypr/modules/appearance.lua` |
| Waybar / Rofi / SwayNC | `waybar/`, `rofi/`, `swaync/` |
| GTK | `gtk-3.0/`, `gtk-4.0/` |

Niri rounds and clips window surfaces to 12px and draws borders without a filled
background, preserving application transparency. Hyprland also has its own Kitty
opacity rule; its appearance can differ from Niri.

## Wallpapers

| Directory | Contents |
| --- | --- |
| `wallpapers/ocean/` | Night sea, subtle brightness lift, and morning variant |
| `wallpapers/legacy/` | Original futuristic city, used by Hyprland and driftwm |
| `wallpapers/archive/rose/` | Earlier pink abstract experiments |
| `wallpapers/archive/ferris/` | Earlier Ferris town wallpapers and SVGs |
| `wallpapers/sources/ferris/` | Original Ferris assets and provenance |

Ferris SVGs can be regenerated with `ruby scripts/build-town.rb` and
`ruby scripts/build-quiet-town.rb`. Rendering to PNG additionally needs ImageMagick.
The SVG output goes to `wallpapers/archive/ferris/`; existing PNG variants stay intact.

The ocean and rose images were created with the built-in image generation tool.
Ferris characters were downloaded from rustacean.net and composed directly into
SVG scenes; they were not generated by AI.
